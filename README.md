# -EG4S20-HDMI-
本作品面向数字广告、展陈展示与信息发布场景，以安路 EG4S20 FPGA 为核心，搭建集图片、视频、音频播放与交互控制于一体的 HDMI 多媒体系统。系统采用自主编写的硬件逻辑，完成 TF 卡数据读取、CRC 校验与异常重试、SDRAM 双帧缓存管理、BC1 图像解码及 HDMI 音视频输出，无需外接处理器参与实时播放。  系统支持 640×480 图像显示与 6 fps 有声视频播放，图片素材可通过配套 Python 工具按比例适配并以黑边填充。图片模式支持手动翻页、自动轮播，以及滑动、二维纸飞机折叠飞出、颗粒消散三种转场；视频模式支持切换、暂停、重播和循环播放。画面叠加媒体序号、播放时间、状态字幕及实时音频波形，并支持亮度调节。
